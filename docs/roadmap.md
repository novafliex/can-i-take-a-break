# 路线图 · roadmap.md

> 区分「已完成 / 进行中 / 规划中」。规划项不代表已实现；已完成项均有代码与测试依据。

## 已完成

### 产品与功能（业务版本 V2.2.1，2026-10-23 口径）

- 核心闭环：申请发布（预设 + 自定义）、两阶段投票（正式 / 后续表态）、限时自动结算、申请后续故事线；
- 社区互动：两级楼中楼评论、点赞、举报、删除、申诉；神评论；默契度；
- 内容频道：「聊两句」文章系统（三栏目、草稿 / 上架 / 下架 / 精选）、文章 → 申请转化闭环；
- 个人中心：XP 等级、我的记录、最近动态、资料编辑；
- 隐私合规：小程序内五类隐私请求与申诉、处理记录查询；
- 管理后台：评论复核、请求处理（含关联评论联动）、Web 管理页、全操作审计；
- 冷启动内容：18 条演示申请 + 15 条时间槽轮换选题 + 33 篇编辑部文章包，全部幂等补种。

### 技术与工程

- Go 后端：零框架、约 40 个接口、双存储同构（JSON / MySQL）、keyset 游标分页；
- 安全：openid HMAC 派生 + AES-GCM 加密、自研 HMAC 令牌、具名管理密钥、fail-closed 内容安全；
- 数据：V6→V7 schema 迁移、legacy 写入围栏触发器、备份 / 恢复 CLI（校验和 + 空库保护）；
- 测试：Go 22 个测试文件（单元 + httptest 端到端 + 真 MySQL 集成）、前端 102 项回归、静态检查与部署守卫；
- 部署：微信云托管（Docker 多阶段、非 root）、两段式部署脚本、/health 与 /health/ready 探针。

### 视觉（V3.0，2026-10-24）

- 三套完整主题（clean / retro / fun）：CSS 变量设计系统 + 原生外壳同步 + 每主题 tabBar 图标；
- 全局可读性下限（正文 ≥21rpx）与组件类名统一。

### 交付链（2026-10-23 ~ 10-25）

- 云端后端发布（2026-10-23，第 032 次发布记录见开发仓库文档）、体验版 2.2.1 上传；
- 102 项前端回归 + 云路径回归实跑（隔离 MySQL 全绿）；
- 仓库瘦身（移出 213MB 演示视频与编译产物）、全部文档核对同步。

## 进行中

- **体验版运营**：核心功能已完成。由于个人主体在社交互动类目上的准入限制，目前通过体验版展示与收集反馈。；
- **文档与展示**：本展示仓库的维护（README、docs、Pages 展示页）。

## 规划中（候选，未开发）

按开发基准文档的口径，以下均为**候选规划**，做不做取决于体验版反馈：

| 方向 | 说明 | 备注 |
| --- | --- | --- |
| 真机体验验收 | 真实多账号投票验收、真机走查与体验反馈整理 | 核心功能已完成，持续验证体验质量 |
| 订阅消息开启 | 配置模板 ID、真实送达验证 | 代码链路已完成并测试，属配置级工作 |
| 备份自动化 | 定时备份任务、云 MySQL 自动备份保留策略确认 | 当前为手动 CLI |
| 结果分享海报 | 生成申请结果卡片供分享 | 设计候选 |
| 成就 / 徽章 | 前端已预留扩展位，**刻意未开发半成品入口** | 等参与数据支撑 |
| 更多互动形态 | PK、盲盒、每日话题等 | 均为候选，未承诺 |
| 已知小缺口修复 | feed 下拉刷新不生效、快捷回复未渲染、接入 wx.getUpdateManager | 见 [features.md](features.md) 第 11 节 |

## 刻意不做

- 复杂积分、排行榜、虚拟货币、强社交关系（关注 / 私信）——违背「低社交压力」定位；
- 机构化包装（「审批局」「局长」）——见 [product.md](product.md) 的语言纪律；
- 用假数据（伪造用户数、伪造测试覆盖率）装饰仓库。
